Kwizzy is an unofficial player: it re-hosts questions locally for offline play and links back to each original quiz. Memory lives in your browser only — nothing is sent anywhere.

Legend — a Answered before badge on a question means it already lives in your browser memory. Custom quizzes draw unseen questions first, then top up with badged ones.
